# Codex Project Instructions

- Read `docs/CODEX_HANDOFF.md` before making changes.
- Treat the repository as the source of truth for current implementation state.
- Use `docs/CODEX_HANDOFF.md` for project intent, architectural decisions, open decisions, and development history.
- Check git status and recent commits before modifying code.
- Preserve existing working behavior unless explicitly asked to change it.
- Never treat `PROPOSED` or `OPEN DECISION` items in the handoff as approved.
- Ask for approval before major architectural changes.
- Make incremental changes rather than large rewrites.
- Run the appropriate typecheck/tests after changes.
- Update `docs/CODEX_HANDOFF.md` after meaningful implementation milestones.
- Never put secrets or credentials in the handoff.
